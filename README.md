# Student Report Card

A simple and organized **Student Report Card** created using **HTML and CSS**. This project displays student academic information, subject marks, grades, and the overall result in a clean report card layout.

## 📌 Features

* Student information section
* Subjects and marks
* Total marks
* Obtained marks
* Grades and overall result
* Clean and organized report card layout
* CSS styling for better presentation
* Proper spacing, borders, and alignment

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure and content of the report card.
* **CSS3** – Used to style the report card and improve its visual appearance.
